# Unified Fact-Verification Benchmark: STAR Project Overview

## SITUATION

The field of automated fact-verification is fragmented, with multiple datasets, inconsistent labeling schemes, and varying evaluation protocols. This makes it difficult to compare systems, understand progress, or identify best practices. There is a need for a unified, reproducible benchmark that harmonizes data, standardizes evaluation, and enables rigorous comparison of fact-verification models and methods.

---

## TASK

- Aggregate and normalize claims and labels from diverse, human-annotated fact-checking corpora.
- Define a unified schema for claim decomposition, evidence retrieval, and global verification.
- Implement robust evaluation protocols to compare decomposition and verification strategies.
- Analyze the performance of various LLMs and aggregation methods.
- Provide a reproducible, extensible framework for the research community.

---

## ACTION

1. **Dataset Scouting & Selection**
   - Surveyed and selected a diverse set of fact-verification datasets (e.g., FactCheck-GPT, FactCheck-Wild, RefChecker, SelfChecker, Reveal, etc.) based on domain coverage, claim complexity, and label quality.

2. **Claim Acquisition & Filtering**
   - Extracted claims generated by various LLMs from each dataset.
   - Filtered out non-verification-worthy statements using heuristics (e.g., entity presence, factual assertion structure).

3. **Gold-Standard Label Harmonization**
   - Implemented per-dataset mappers to convert original labels into a unified numeric space {–1, 0, 0.5, 1}.
   - Collapsed ambiguous classes (e.g., 0.5) into supported labels to address class imbalance.

4. **De-duplication & Conflict Resolution**
   - Identified and removed duplicate claims across datasets.
   - Applied majority-vote or source-priority rules to resolve conflicting gold labels.

5. **Metadata Preservation & Annotation**
   - Tagged each claim with metadata: dataset source, LLM version, annotation version, domain/topic, decomposition type, and complexity.

6. **Evidence Availability Verification**
   - Checked for the presence of supporting/refuting evidence in the retrieval corpus.
   - Flagged unanswerable claims as NEI (Not Enough Information).

7. **Decomposer Performance Evaluation**
   - Implemented and tested multiple decomposition methods (sub-sentence, full-sentence, triple concatenation/merging).
   - Used different LLMs (LLaMA3-8B, Mistral-7B) to generate decompositions.
   - Applied aggregation strategies (fact-score, conservative) to combine fine-grained verification results.

8. **Evaluation Pipeline**
   - Orchestrated the end-to-end process: decomposition, verification (using LLaMA3-8B and others), aggregation, and metric computation (accuracy, precision, recall, Macro F1).

9. **Verifier Experiments with LLMs**
   - Evaluated various LLMs (Mistral-7B, LLaMA2/3, GPT-3.5, GPT-4, Claude3) as verifiers using zero-shot and few-shot prompts.
   - Compared sentence-based and triple-based decompositions, and natural-language reconstructions.

10. **Reproducibility & Documentation**
    - Provided scripts, prompt templates, and documentation for data creation, model runs, and evaluation.
    - Maintained a versioned, extensible codebase and paper draft.

---

## RESULT

- **Unified Benchmark:** Created a standardized, reproducible benchmark for fact-verification, harmonizing multiple datasets and protocols.
- **Improved Comparability:** Enabled rigorous, apples-to-apples comparison of decomposition and verification methods.
- **Key Findings:**
  - Sub-sentence decomposition with fact-score aggregation achieved the highest accuracy on some datasets.
  - Conservative aggregation was more robust on others but tended to under-predict support.
  - LLaMA3-8B outperformed Mistral-7B for decomposition generation.
  - Refchecker_text (natural-language triple reconstructions) yielded the best Macro F1 (up to 0.56).
  - 6-shot prompting and instruct-tuned models significantly improved verifier performance.
- **Community Impact:** The framework, code, and findings provide a foundation for future research and development in automated fact-verification.
