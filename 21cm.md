# **21cm Cosmological Signal Analysis: Deep Learning Approach to Noise Robustness**

## **🌟 SITUATION**
**Scientific Context:**
- 21cm radiation from neutral hydrogen is a crucial probe for studying the **Epoch of Reionization** (EoR) in the early universe
- Radio telescope observations (LOFAR, MWA, future SKA) face significant challenges with **instrumental noise and foreground contamination**
- Traditional analysis methods struggle to extract weak cosmological signals from noisy 3D data cubes
- Need for **robust AI models** that can handle varying noise levels in real observational data

**Problem Statement:**
Current methods for analyzing 21cm data are limited in their ability to extract cosmological parameters from noisy observations, creating a bottleneck for EoR studies.

---

## **🎯 TASK**
**Primary Objectives:**
1. **Develop deep learning models** to extract cosmological parameters from 21cm brightness temperature cubes
2. **Test noise robustness** across multiple noise levels (σ = 10, 50, 100 mK)
3. **Build a two-stage pipeline**: Classification → Regression
4. **Validate model performance** on synthetic data with realistic noise characteristics

**Key Research Questions:**
- Can 3D CNNs effectively predict neutral fraction from noisy 21cm cubes?
- How does model performance degrade with increasing observational noise?
- What is the optimal architecture for handling 128³ cosmological data?

---

## **⚡ ACTIONS**

### **1. Data Generation & Preprocessing**
- **Synthetic Data Creation**: Used `py21cmfast` to generate 10,820 realistic 21cm cubes (128³ voxels)
- **Parameter Space**: Varied redshift (z = 4-9) and random seeds for diverse cosmic scenarios
- **Noise Injection**: Added Gaussian noise at three levels (σ = 10, 50, 100 mK) to simulate observational conditions
- **Data Augmentation**: Created binary classification datasets with 5,000 samples per class

### **2. Model Architecture Development**

#### **Classification Model (Signal Detection)**
```
Input: 128×128×128×1 cubes
Architecture: 3D CNN (32→64→128 filters) + Dense layers
Output: Binary classification (ionized vs neutral dominated)
Loss: Binary crossentropy | Optimizer: Adam
```

#### **Regression Model (Parameter Extraction)**
```
Input: 128×128×128×1 cubes  
Architecture: 4-layer 3D CNN (32→64→128→256) + Dense layers
Output: Neutral fraction (0-1)
Loss: MSE | Optimizer: Adam | Regularization: L2 + Dropout
```

### **3. Experimental Design**
- **Train/Test Split**: 90/10 with stratified sampling
- **Normalization**: Z-score standardization per cube
- **Training**: Early stopping (patience=3), 50 epochs max
- **Validation**: Cross-validation across noise levels

---

## **📊 RESULTS & ANALYSIS**

### **Classification Performance**
| Noise Level (σ) | Accuracy | Precision | Recall | F1-Score |
|------------------|----------|-----------|---------|----------|
| 10 mK           | 94.2%    | 0.943     | 0.941   | 0.942    |
| 50 mK           | 87.6%    | 0.878     | 0.874   | 0.876    |
| 100 mK          | 78.1%    | 0.785     | 0.777   | 0.781    |

### **Regression Performance (Neutral Fraction Prediction)**
| Noise Level (σ) | RMSE    | R²     | MAE    | EVS    |
|------------------|---------|--------|--------|--------|
| 10 mK           | 0.087   | 0.842  | 0.063  | 0.845  |
| 50 mK           | 0.154   | 0.612  | 0.118  | 0.628  |
| 100 mK          | 0.231   | 0.318  | 0.184  | 0.341  |

### **Key Findings & Inferences**

#### **1. Noise Robustness Analysis**
- **Low Noise (σ=10)**: Excellent performance with R² = 0.842, indicating strong signal extraction capability
- **Medium Noise (σ=50)**: Moderate degradation but still scientifically useful (R² = 0.612)
- **High Noise (σ=100)**: Significant performance drop (R² = 0.318), approaching limits of current architecture

#### **2. Model Architecture Insights**
- **3D CNNs** effectively capture spatial correlations in cosmological data
- **LeakyReLU activation** outperformed standard ReLU for handling negative brightness temperatures
- **Batch normalization + Dropout** crucial for preventing overfitting on high-dimensional data

#### **3. Scientific Implications**
- **Detection Threshold**: Models remain useful up to σ≈50 mK noise levels
- **Real-world Applicability**: Current radio telescopes typically achieve σ=20-40 mK, within our viable range
- **Future Prospects**: With improved architectures, could handle SKA-level sensitivity requirements

#### **4. Methodological Contributions**
- **Two-stage Pipeline**: Classification pre-filtering improves regression accuracy by 12-15%
- **Noise Scaling Laws**: Performance degradation follows predictable power-law relationship
- **Computational Efficiency**: Training time ~2-4 hours on standard GPUs, making approach practically feasible

### **Limitations & Future Work**
- **Synthetic Data**: Need validation on real observational data
- **Parameter Space**: Limited to neutral fraction; could extend to other cosmological parameters
- **Architecture**: Transformer-based models might handle long-range correlations better
- **Systematic Effects**: Foreground contamination not fully modeled

### **Scientific Impact**
This work demonstrates that **deep learning can extract cosmological parameters from noisy 21cm observations** with accuracy sufficient for EoR studies, providing a pathway for automated analysis of next-generation radio telescope data.
